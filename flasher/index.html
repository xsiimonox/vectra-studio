Vectra Schachtwächter

Installiert die ESPHome-Firmware für einen Wemos D1 mini mit VL53L0X direkt per USB.

  1. D1 mini per Daten-USB-Kabel anschließen.
  2. Chrome, Edge oder einen anderen Browser mit Web Serial verwenden.
  3. Auf Connect klicken und den seriellen Anschluss wählen.
  4. Nach dem Flashen WLAN direkt im Browser einrichten. Falls dies übersprungen wird, steht das WLAN Vectra Schachtwächter Fallback bereit.
  5. Das Gerät danach in Home Assistant als Vectra Schachtwächter übernehmen und dort Leerabstand auf den Abstand von Sensorlinse bis trockenem Schachtboden in cm setzen.

Achtung: Das Browser-Flashen löscht den D1 mini. Der Leerabstand wird danach direkt in Home Assistant kalibriert.
